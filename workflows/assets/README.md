# 图片备份

2026-09-18 的图片快照，非自动同步目录。

- `uploads/`：本地 `data/uploads/` 下的上传与生成图片，保留原有相对路径。
- `remote/`：`首版.workflow.json` 引用的远程 PNG 原图。
- `manifest.json`：每张图片的原始路径或 URL、备份路径、大小与 SHA-256。

原始工作流未修改，远程图片链接仍指向原服务。若链接失效，可在项目中上传 `remote/` 中的图片，再替换工作流节点的图片。
恢复本地图片时，将 `uploads/` 中所需文件复制到项目的 `data/uploads/`，保留相对路径；不要覆盖已有同名文件。这里只备份图片，不包含素材数据库，复制文件不会自动恢复素材库记录。

不包含数据库、环境变量、调试截图及视频。工作流中的 5 处远程链接实际重复引用 1 张图片和 1 个视频，本次仅备份图片。
